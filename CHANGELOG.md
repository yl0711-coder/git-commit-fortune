# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

- Added `--strict` mode for CI-friendly exit codes when risky commit patterns are detected.

## v0.1.1 - 2026-04-22

- Added `--since` support for Git-native time windows.
- Added compact `--one-line` output.
- Added Chinese README and bilingual documentation maintenance notes.
- Added extra fortune templates for verbose commit history.
- Clarified local-time handling when analyzing commit hours.

## v0.1.0 - 2026-04-22

- Initial local CLI for reading Git commit history and generating a repository fortune.
- Added omen, fortune level, and lucky command output for more screenshot-friendly reports.
